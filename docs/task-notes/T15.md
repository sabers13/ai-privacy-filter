# T15 task notes

## Scope

Release documentation and gates: the public README, `project-facts.yml`, the
clean-clone check, the licence inventory and the `v1.0.0` tag. T15 changes no
detection, pseudonymisation, backend or triage behaviour except the two small
reproducibility/reliability fixes below.

## Decisions

- **The README starts from the problem, not the architecture.** The first
  screen says what leaves the machine, shows a real page example, and gives the
  four headline numbers with intervals and links. The backend table carries the
  data-handling note for each route, including the Codex read limit instead of
  claiming a read jail.
- **Every bolded number is a link.** `tests/test_project_facts.py` fails if a
  bolded number in the README has no result-file link, or if an evidence path
  in `project-facts.yml` does not exist. This keeps the release document from
  drifting away from `results/`.
- **The clean-clone gate removes the private environment, not the network.**
  It clones with `git clone --no-local`, unsets every `AIPF_*` variable, runs
  `make setup test reproduce`, verifies `results/SHA256SUMS`, and requires no
  tracked file under `results/` to change. It never sources the private env
  file. The optional GermEval download is allowed to happen, and is checked
  against the committed hashes.
- **Reproduction is idempotent.** `make reproduce` previously rewrote the
  triage run's `generated_at`, making the worktree dirty even when every number
  matched. It now keeps the recorded timestamp on a successful reproduction.
- **The scanner decodes history as bytes.** `git log -p` can emit non-UTF-8
  bytes from a binary blob. `scan_history()` now decodes with
  `errors="replace"`; a regression test commits a non-UTF-8 blob and a leak in
  the same history.
- **`--path` scopes a scan without hiding a subtree.** The site repository is a
  portfolio with unrelated pages. The release scan is the project repo's full
  history plus the page subtree's full history, not the captain's public
  contact block on the portfolio's home page.
- **One documented page-history exception.** The page subtree's history has one
  hit in a superseded commit: a common German first name in the generated Faker
  name export, removed in `0797d25`. The current page tree is clean. The value
  is not reproduced in this repository or in the release check. The site
  repository is shared, so its history was not rewritten.
- **The page credits were completed.** The site page now names every component
  and licence in `THIRD_PARTY.md`, including the transitive runtime libraries,
  development tools, the local Qwen model and the SaberOps attribution. The
  change is a local commit on the site repository's `main`; nothing was pushed.
- **The tag is local.** `v1.0.0` is annotated and points at the release commit.
  No remote exists; nothing was pushed, merged or deployed.

## Deliberately absent

- No remote, no push, no pull request, no deployment and no tag push.
- No history rewrite of the shared site repository.
- No real customer data, real-person example, private hostname, private IP,
  home path or key in either repository or the page.
- No compliance or legal claim. The project pseudonymises; it does not make
  text anonymous, and it is not legal advice.
