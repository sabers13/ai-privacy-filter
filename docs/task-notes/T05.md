# T05 task notes

## Scope

Download and parse GermEval 2014 NER for a held-out detection evaluation. No
detector is evaluated yet; T05 delivers the loader, provenance and parser that
later tasks consume.

## Decisions

- **Download route.** The original GermEval 2014 site points to a Google Drive
  folder. The per-file Drive links answered `HTTP 200` directly on 2026-10-27
  with no confirmation page, for `curl` and `httpx` alike, so the original source
  is used. The folder was listed non-interactively too, confirming the published
  `NER-de-train.tsv`, `NER-de-dev.tsv` and `NER-de-test.tsv` names and ids; the
  labelled test file is used, not the unlabelled one. The Hugging Face mirror
  `GermanEval/germeval_14` was not needed; its dataset loading script was never
  run, because it requires arbitrary Python execution. The mirror remains the
  documented fallback, and its auto-converted Parquet files are the only
  acceptable mirror form.
- **Integrity over convenience.** Each split is pinned by URL, byte size, SHA-256
  and published sentence count in `SPLIT_SOURCES`. An existing file is reused
  only when both integrity checks pass; a mismatch is re-downloaded, and a fresh
  download that still mismatches fails the run. The pinned revision is the one
  after the page's 28/4/22 encoding fix.
- **Outer spans only.** The published format has outer tags in column three and
  nested tags in column four. Detection is evaluated on outer spans, so the
  nested column is parsed away (never validated as an entity). The documented
  embedding example (`ORG` containing a nested `LOC`) therefore yields one `ORG`
  span.
- **Mapping.** `PER` maps to `EntityType.PERSON`, `ORG` to `EntityType.ORG`, and
  those two classes alone form the primary metric. `LOC` becomes the
  loader-only `LOCATION` class and is reported separately: a place name is not
  personal data by itself. `OTH` becomes `OTHER` and is not scored. `deriv` and
  `part` tags each get their own class and are excluded from the primary metric.
  `EntityType` is unchanged, so the frozen T01 contract does not grow a
  location member.
- **Text assembly.** Tokens are joined with single spaces; span offsets index
  that joined text. Tests assert `text[start:end] == span.text` for every span.
- **BIO tolerance.** A real corpus can start a span with `I-` or switch type
  without `B-`. The parser closes the previous span and opens a new one instead
  of rejecting the sentence. Token indices are still validated, because a gap
  means the file is truncated or corrupted.
- **Two shape quirks.** One test sentence has a quoted token line with a
  trailing fifth (empty) tab column, and one header has only three columns.
  Both are accepted; fewer than four token columns, a missing header or an empty
  sentence is a format error.
- **Privacy in failure.** Parser errors name the split, line number and tag
  only. Token text is never included in an exception or a log line, and parsed
  JSONL stays in the git-ignored data directory.
- **No Parquet dependency.** Because the original TSV links worked, `pyarrow`
  and the Hugging Face `datasets` package are not added. Parsing is plain
  Python over the published format.
- **Outputs.** `data/external/germeval/` holds the three TSVs,
  `parsed/<split>.jsonl`, `parsed/<split>.stats.json` and `manifest.json`.
  Nothing there is tracked.

## Verification

- `uv run python data/get_germeval.py` (real run, 2026-10-27): train 24,000
  sentences / 452,853 tokens / 29,078 spans / 12,934 primary; dev 2,200 /
  41,653 / 2,674 / 1,207; test 5,100 / 96,499 / 6,178 / 2,789. Published split
  sizes matched.
- `make lint` (ruff check, ruff format check, `mypy --strict src`).
- `make test` with invented GermEval-format fixtures only; no real line is in
  the repository.
- `git ls-files data/external` is empty, asserted by a test.
- `make scan-forbidden`, `make secrets`. `.gitleaks.toml` excludes only the
  git-ignored external data: GermEval citation URLs contain `key=` query strings
  that the generic-api-key rule reports as false positives. The tracked tree and
  history remain fully scanned.
- `data/SOURCES.md` is checked against `SPLIT_SOURCES` by a test, so URLs,
  sizes, counts and checksums cannot drift silently.

## Deliberately absent

- No detector evaluation, no page data, no LLM call, no server access.
- No real GermEval sentence in code, tests, docs or logs.
- No Hugging Face loading script or `datasets` dependency.
- No push, remote, pull request or deployment.
