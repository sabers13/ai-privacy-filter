# T03 task notes

## Scope

`pseudonymise.py` and `guard.py` implemented against T01's `models.py`, plus the
local-only proof module `tests/test_local_only.py`. T02's detector is not
imported for its internals; the tests use the `Span` contract and the synthetic
fixture corpus, and the no-network module calls `detect.detect` only through its
public signature.

## Decisions

- **Redaction reads the source text, not `span.text`.** The slice
  `text[span.start:span.end]` is authoritative, so a stale span label cannot
  insert text that is not in the source.
- **Placeholder numbering.** Counters are per `EntityType` and start at 1 in
  order of first appearance. Equal values reuse one placeholder for the whole
  message. Equality is NFC, `str.casefold()` and whitespace-collapsed, shared by
  `redact`, `restore` and `guard` through `normalise_value`.
- **Dedupe key is the normalised value across types.** If the same string is
  detected once as `ORG` and once as `PERSON`, the first detection's placeholder
  (and therefore type) wins for every later occurrence. This keeps one value,
  one placeholder, as the contract requires.
- **Overlap policy.** Spans are sorted by start, then longer first, then type and
  source for determinism. A span that starts inside an already accepted span is
  dropped. Empty, whitespace-only and out-of-range spans are ignored. The
  returned `spans` list contains exactly the replaced spans, including repeated
  occurrences of a deduplicated value.
- **Restore tolerance.** A placeholder is looked up by canonical form: brackets
  optional, case-insensitive, runs of spaces/underscores collapsed, zero-padded
  index trimmed (`[ person _ 01 ]` restores as `[PERSON_1]`). Unknown or invented
  placeholders are left as written and reported once each in order of first
  appearance.
- **Round-trip caveat.** Because the mapping stores one original per placeholder,
  a repeated value restores to its first written form. Texts that repeat a value
  with different casing or spacing share a placeholder and therefore restore to
  the first form; exact repeats round-trip byte for byte. The 50-text fixture
  corpus uses exact repeats. T04's 500-text set needs the same constraint for a
  strict `redact -> restore == original` property, or the property needs to be
  stated as equality after normalisation.
- **Guard.** Every mapped original is checked in normalised form. `PHONE` and
  `IBAN` are additionally checked digit-only with at least four ASCII digits, so
  `0170 1234567`, `0170/1234567` and `01701234567` all match. Four digits keeps
  short numbers such as a house number from matching by accident while still
  covering realistic phone and IBAN digit runs. Types are reported in mapping
  order, deduplicated.
- **Blocking helper.** `guard.require_clean` raises `GuardBlockedError` instead of
  returning, so pipeline code cannot reach the model by forgetting to inspect
  `verdict.ok`. The exception message and the verdict carry types only.
- **No logging of values.** Neither module logs. The guard writes one debug line
  with the number of leaked types, never a value. Tests capture `caplog` for
  `redact`, `restore` and `guard` and assert that no original value appears.
- **Fixture corpus.** 50 texts from 10 hand-written German templates rendered
  with five Faker `de_DE` value sets (fixed seed). The generator is a scratch
  script outside the repository; the committed JSON carries exact spans. Every
  record is validated with `redact`, `guard` and `restore` before it is written,
  so a fixture that would trip the guard cannot enter the repository.
- **No-network proof.** `tests/test_local_only.py` carries
  `pytest.mark.disable_socket`, so it runs with sockets blocked under plain
  `make test` and under `pytest --disable-socket`. It first proves the block is
  active, then walks redaction, the guard, the fake model and restoration over
  all 50 texts. The detector leg calls `detect.detect` under the same blocked
  sockets; T02 replaced the stub, so the real Presidio engine is exercised with
  the network unavailable.

## Deliberately absent

- No Presidio, spaCy model or detector internals imported directly; the
  detector is exercised only through `detect.detect`.
- No live LLM call, no network, no GermEval data, no page data.
- No real people, companies or infrastructure; all fixture values are synthetic.
- No placeholder escaping for source text that already contains `[TYPE_n]`
  literals. Such a literal would be restored like a real placeholder; no test or
  fixture uses one, and the hazard is noted here rather than guessed at.
