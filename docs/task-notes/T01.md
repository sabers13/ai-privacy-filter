# T01 task notes

## Scope

Foundation and contracts only. Detection, pseudonymisation, the guard, the HTTP
service, the CLI and the real backends are typed stubs that raise
`NotImplementedError`. The fake backend is fully implemented so later tasks can
run the whole pipeline with no network.

## Decisions

- **Package name and layout.** Distribution `ai-privacy-filter`, import package
  `ai_privacy_filter`, `src/` layout, Python `>=3.12`, `uv_build` backend,
  `aipf` console script.
- **Model base class.** Frozen pydantic v2 models with `extra="forbid"`. The
  redaction mapping is excluded from `repr` so a stray log line cannot print a
  personal value.
- **Extra contract.** `RestoreResult` carries the restored text plus unknown
  placeholders, so the T03 restore step can report invented placeholders without
  changing the return type later.
- **Fake backend.** Answers are a pure function of the prompt's SHA-256 digest:
  category, urgency, template choice and latency all derive from it. The reply
  reuses the first placeholder found in the prompt, which exercises the restore
  step. No network, no model download, no clock or random source.
- **Registry.** `get_backend` constructs a backend by name and
  `available_backends` lists registered names without probing them. Probing a
  stub would raise; availability checks stay explicit.
- **Scanner.** Two rule sets: built-ins (RFC 1918 and CGNAT ranges, absolute home
  paths, Tailscale hostnames, API-key-shaped prefixes, PEM private-key blocks)
  and literal patterns from `AIPF_FORBIDDEN_FILE`. Output names the file, line
  and rule label only. History scanning inspects added lines in `git log -p`.
- **gitleaks.** Pinned to v8.30.1, installed into `~/.local/bin` by
  `make secrets-install`; `make secrets` falls back to a pinned podman image.
- **spaCy model.** `spacy download de_core_news_lg-3.8.0` rejected the pinned
  name on spaCy 3.8.18 ("no compatible package"). `make setup` therefore installs
  the pinned model wheel directly from the official spaCy models release URL with
  `uv pip install --no-deps`; same 3.8.0 artefact, deterministic URL. Because the
  model lives outside `uv.lock`, rerun `make setup` after changing dependencies:
  `uv sync` prunes it and the setup step reinstalls it.
- **CI.** Runs ruff, `mypy --strict src` and `pytest -m "not live and not e2e"`.
  The German spaCy model is not downloaded in CI because no test needs it.
- **Stub targets.** `reproduce`, `live`, `e2e` and `page-data` print an honest
  message and exit non-zero rather than pretending to succeed. `release-check`
  runs only gates that exist today.

## Deliberately absent

- No GermEval download, no synthetic dataset, no live LLM call, no server access.
- No remote, no push, no pull request, no deployment.
- No real people or real company data; page/demo snippets use placeholders.

## Verification

- `make lint` (ruff check, ruff format --check, mypy --strict on `src/`).
- `make test` (contract, stub and scanner tests).
- `make secrets` (gitleaks against working tree and history).
- `make scan-forbidden` (built-ins plus the private pattern file when loaded).
