# T08 task notes

## Scope

`api.py` (FastAPI service), `tickets.py` (in-memory ticket store), `pipeline.py`
(the shared detect -> redact -> guard -> model step) and `cli.py`
(`aipf redact|process|eval|serve`), plus the TestClient and CLI tests.

T02's `detect.detect` and T06's `triage.classify` are still stubs on `main`, so
the service is built against the frozen contracts with an injectable detector and
classifier. `pipeline.default_detector` and `pipeline.default_classifier` call
the real modules, so nothing has to change in the service when those tasks land.

## Decisions

- **Pipeline owns the order, not the endpoints.** `Pipeline.process` runs
  detect, `pseudonymise.redact`, `guard.require_clean` and only then the
  classifier. The guard is inside the pipeline, so neither the HTTP service nor
  the CLI can call the model by forgetting to check the verdict. T03's
  `require_clean` raising is what turns a leak into a 422 / exit code 2.
- **Injection, not monkeypatching, for the stubs.** `create_app(pipeline=...,
  tickets=...)` takes stand-ins explicitly. Tests pass a deterministic detector
  over synthetic text and a classifier that calls the real `FakeBackend` with
  `TRIAGE_SCHEMA`, so the fake backend and the schema are genuinely exercised.
  A stub upstream raises `NotImplementedError`; the pipeline converts that to
  `PipelineNotReadyError` naming the owning task, and the service answers 501
  with that message instead of a traceback. This is a temporary state: T02 and
  T06 replace the stubs, and the 501 path then stops being reachable.
- **Ticket instead of mapping.** `/redact` returns `ticket` and
  `expires_in_s`; the mapping stays in `TicketStore`. `expires_in_s` is rounded
  from the TTL so a caller can refresh before the 15-minute expiry.
- **Unknown and expired tickets answer the same 410.** Both are "gone"; telling
  them apart would make the endpoint an oracle for whether a ticket ever
  existed, and the caller's only action is the same either way.
- **Ticket store is bounded.** Default 512 live tickets. Issuing purges expired
  entries first, then evicts the oldest insertion when still full, so a caller
  that never restores cannot grow process memory without limit. Ids come from
  `secrets.token_urlsafe(24)`. The store copies the mapping in and out, so a
  caller cannot mutate stored values through a returned dict.
- **Thread safety.** FastAPI runs sync endpoints in a thread pool, so the store
  guards its dict with a `threading.Lock`. `len(store)` is used by tests to prove
  expiry actually drops entries.
- **`/process` returns `redacted_text` on purpose.** The brief asks n8n reviewers
  to see what left the machine, and the response is the exact string the
  classifier received (asserted in tests by inspecting the spy's argument).
  `ProcessResult.mapping` is `repr=False, exclude=True`, so the mapping cannot
  reach a response body through `model_dump`.
- **`/process` does not restore the draft.** Restoration needs the mapping, and
  `/process` issues no ticket by design in this task. The CLI restores locally
  with `--restore`; the n8n flow (T13) can call `/redact` and `/restore` for that.
- **Validation errors are re-shaped.** FastAPI's default 422 includes the
  offending `input` value, which for this service would put personal data in an
  error body (and into anything that logs responses). The handler keeps `loc`,
  `msg` and `type` only. Tested with an over-length body that contains a name.
- **Logging.** One info line per endpoint with character counts, span counts,
  unknown-placeholder counts, backend name and latency. Nothing else. Tests
  capture `ai_privacy_filter.api` records and assert no original value and no
  placeholder appears. Uvicorn's access log records the path and status only.
- **CORS stays off.** No `CORSMiddleware`; a request with an `Origin` header gets
  no `access-control-allow-origin`, and a preflight is not answered. The service
  is a local component, not a browser API.
- **Bind.** `127.0.0.1:8765` by default. `AIPF_BIND=host:port` overrides it
  (`:port` keeps the loopback host, `[::1]:port` is accepted for IPv6).
  `--host/--port` on `aipf serve` override both. `serve --reload` uses the
  `create_app` factory string because uvicorn's reloader needs an import string.
- **`eval` is a stored-results summary, not a recompute.** The page data that a
  recompute would need is T11/T13's. The command validates `results.json` with
  `PageResults` and prints the stored detection, triage and meta blocks, and says
  so when no file exists.
- **Text limit.** 20 000 characters per request (`MAX_TEXT_CHARS`), enforced by
  the request models, so one request cannot pin an arbitrary amount of memory.
- **`ContractModel` reuse.** Request and response models inherit the frozen
  `extra="forbid"` contract base, so unknown fields are rejected (tested).

## Deliberately absent

- No detection, no triage prompt, no real backend wiring: those are T02 and
  T06/T12. No live call and no network access in any test.
- No authentication or rate limiting. The service is loopback-only by default
  and T13's n8n run is local; adding a token scheme would be a product decision
  this task does not own.
- No persistence of tickets, no cookies, no session middleware.
- No n8n workflow and no deployment; nothing is pushed.
- No real personal data: the test text is synthetic and the entity values are
  invented.
